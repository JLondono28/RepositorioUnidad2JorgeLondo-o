Respuesta: 2^N  
  
### Ejercicio 2:  
    "Convierte el número decimal 22 a binario"  
Respuesta:  
    22 / 2 = 11, residuo 0  
    11 / 2 = 5, residuo 1  
    5 / 2 = 2, residuo 1  
    2 / 2 = 1, residuo 0  
    1 / 2 = 0, residuo 1  
    Residuos de abajo hacia arriba, por lo tanto: 22_{10} = 10110_{2}  
  
### Ejercicio 3:  
    "¿Cuál es el resultado en decimal del número binario 10110?"  
Respuesta:  
    1 * (2^4) + 0 * (2^3) + 1 * (2^2) + 1 * (2^1) + 0 * (2^0) = 22
